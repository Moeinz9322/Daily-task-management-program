# 🗓️ Daily Task Manager

A simple, beautiful, and user-friendly **web application** for managing your **daily tasks**,
with **automatic saving** in the browser.
This app does **not require a server or database** and is built using **HTML, CSS, JavaScript, and LocalStorage**.

## 🚀 Features

✅ Add new tasks with a specific date

✅ Edit task text and date

✅ Mark tasks as completed

✅ Delete tasks with smooth animation

✅ Filter tasks by status:

* Today
* Tomorrow
* Past
* No date
* All tasks
* Completed

  ✅ Task statistics (total, completed, pending)

  ✅ Automatic saving in the browser (LocalStorage)

  ✅ Modern UI with gradient colors and responsive design

  ✅ Built-in help modal

## ⚡ How to Run (Locally)

### 🔹 Method 1: Run locally on your system

1. Clone or download the repository:

   ```bash
   git clone https://github.com/Moeinz9322/Daily-task-management-program.git
   cd daily-task-manager
   ```
2. Double-click `index.html` (or open with VS Code and run with Live Server).
3. The app will open in your browser and is ready to use 🎉

---

### 🔹 Method 2: Run online in GitHub Codespaces

If you are using GitHub Codespaces:

1. Click **“Code → Open with Codespaces”**.
2. When the environment opens, run the following command to start a local server:

   ```bash
   npx serve .
   ```
3. GitHub will create a **Forwarded Port**. Click it to open the app in the browser 🌐

---

## 🧠 How It Works

* When adding a task, the data is saved in `localStorage`.
* Tasks are automatically preserved when reopening or closing the browser.
* Filters (Today, Tomorrow, Past...) work based on the user’s system date.
* The help section (`help modal`) opens with the info button (`i`) at the top.
